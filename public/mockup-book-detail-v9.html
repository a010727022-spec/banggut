  • 종료 조건 분기: 뽀모도로 = elapsed >= 25*60이면 auto-complete · 스톱워치 = 사용자 "종료" 탭 시에만 complete

🎨 시각 언어 (Claire)

  • 세그먼트 탭 OFF는 var(--ink3) · ON은 모드별 색상(--mint or --honey) + 흰 배경에 옅은 shadow로 "탭 올라온 느낌"
  • 스톱워치 pulse 도트: @keyframes sw-pulse — inset box-shadow 0→3px, 2s ease-in-out 주기 · prefers-reduced-motion에서는 정적으로 고정
  • 스톱워치 "종료" 버튼은 linear-gradient(135deg, var(--honey), var(--honey2)) — "이건 내가 끝낸다" 는 사용자 의지를 primary 액션으로 격상
  • 완료 배너: 뽀모도로=mint 그라디언트(v8 그대로) · 스톱워치=color-mix(in srgb, var(--honey) 22%, var(--sf)) 꿀색 틴트
  • Focus Card 자동 활성 + pre-selected chip: 뽀모도로=+20 고정 · 스톱워치=경과 시간에 따라 +{22, 27, ...} 동적 계산(분당 0.8쪽 가정 — Emily 제안)

3-state 전환 로직

  1. 대기: 1-line 카드 · "25분 집중 읽기" · "시작" 버튼 · Focus Card는 정상 활성 (사용자 선택)
  2. 진행중: 큰 카드로 확장 · 원형 링 94×94 + 카운트다운 · Focus Card는 .dim 으로 비활성 (중복 입력 방지) · 일시정지/중단 2-버튼
  3. 완료: 축하 배너 (시작~종료 시각 · 누적 시간 표시) · Focus Card 자동 활성 + chips +20 pre-selected · 사용자는 CTA 한 번만 탭하면 쪽수 저장 + 세션 로그 완성

구현 메모 (Dan)

  • 타이머: performance.now() 기준 startedAt ref + setInterval(1000). 백그라운드 탭 복귀 시 elapsed = now - startedAt으로 재계산 (drift 0)
  • 상태: useReducer — {status:'idle'|'running'|'paused'|'done', startedAt, elapsed, pausedAt}
  • localStorage: reading_session_<bookId> — 앱 재진입 시 active session 복원. 25분 초과로 지난 세션은 폐기
  • DB: 신규 테이블 reading_sessions — (id, user_id, book_id, started_at, ended_at, duration_seconds, pages_read_delta). 완료 시점에 INSERT
  • 알림: 25분 만료 시 (a) 탭 포커스 시: pomo-done 배너 pop-in + Focus Card 자동 활성 (b) 탭 미포커스: Notification API (권한 있으면)
  • 일시정지: status:'paused' 저장 · 링은 멈춘 각도 유지 · 재개 시 pausedAt 기준 delta 빼고 계산
  • 중단: 세션을 reading_sessions에 ended_at = now, pages_read_delta = 0로 저장 (데이터는 남기되 기록 없음으로)

시각 언어

  • 대기 카드: Focus Card처럼 sf 배경 + 좌측 mint 바 (streak과 비슷한 가로 리듬)
  • 진행중 카드: 민트 틴트 배경 그라디언트 + 상단 민트 bar + pulse 도트로 "살아 있음" 표시
  • 원형 링: stroke-width 6, r=44 (2πr=276.46) — 25분 동안 stroke-dashoffset 0 → 276.46 선형 보간 (CSS transition 1s step)
  • 완료 카드: mint 강한 accent + pop-in (scale 0.96→1, 0.4s) · prefers-reduced-motion 시 skip
  • Focus Card dim: opacity 0.5 + 반투명 overlay (Pretendard 앱 가이드와 일치 — 비활성은 흐림으로만)

엣지 케이스

  • 세션 중 앱 종료 후 재진입: localStorage에서 복원, 만료 지났으면 '완료' state로 바로 진입
  • 25분 중 사용자가 직접 쪽수 저장: Focus Card에 수동 입력 가능 (dim이지만 tap으로 깨우기). 세션은 계속 진행 또는 자동 종료 옵션 — 자동 종료 + 즉시 완료 state로 결정
  • Group 책에서 누를 경우: 이번 범위 제외 — Group UI 그대로 · 추후 판단
  • 여러 책 동시 세션 방지: localStorage에 reading_session_active(book_id) 저장. 다른 책에서 시작하려고 하면 "현재 책에서 진행 중이에요" 토스트

🔒 완독 후 해금 패턴 (v8 신규)

  • 철학: 읽는 중에는 "책과 나" 둘만의 시간 — 방긋 AI 토론과 서평은 책을 다 읽은 뒤에 열려요. 성급한 평가 대신 감상을 기다려 주는 UX
  • 잠금 대상: (a) 방긋 AI 토론 entry — "책을 다 읽고 만나요" (b) 서평 쓰기 sub — "완독 후 열려요"
  • 활성 유지: 문장 긋기 sub는 읽는 중 핵심 도구라서 잠그지 않음. 모든 state(대기·진행중·완료)에서 상시 활성
  • 시각 언어: opacity:0.62 + background:var(--bg2) + 아이콘 tint를 var(--sf2)로 중화 · 서브카피 앞에 12px 자물쇠 아이콘 · pointer-events:none + aria-disabled="true"로 접근성 대응
  • 해금 조건: book.status === 'finished' 되는 순간 자물쇠 해제 + 같은 자리에서 active 상태로 전환 (레이아웃 점프 없음)
  • 첫 해금 축하: 완독 직후 상세 재진입 시 AI 토론 entry에 pop-in 애니메이션 + "드디어 얘기할 시간이에요" 한 번만 노출 (localStorage 플래그로 중복 방지)
  • 구현: resolveBookDetailVariant(book)에서 review_unlocked = book.status === 'finished' 플래그 반환 → 각 컴포넌트가 locked 클래스 토글
