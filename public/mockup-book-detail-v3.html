드림팀 · 책 상세 '읽는 중' v3 설계 근거

BEFORE (현재 3개 진행률 업데이트 중복)

  • HERO 280px 고정 (어두운 그라데이션)
  • Quick Actions 3개 중 '진행률 업데이트' 버튼 → bottom sheet
  • 진행률 섹션 slider + 저장 버튼 (인라인 업데이트)
  • '오늘 읽었어요' primary 버튼 → 같은 bottom sheet
  • '꾹 누르기' 완독 — 2초 hold + 링 애니메이션
  • 중단/삭제 — 페이지 최하단 작은 링크

AFTER (v3)

  • Sticky 헤더 88px — 표지(44×62) + 제목 + 현재/전체/% inline + Kebab. 스크롤해도 언제든 '어디까지 왔는지' 보임
  • Focus Card — "오늘 몇 쪽까지 읽었어요?" + +10/+20/+30/직접 칩 + 단 하나의 primary CTA. 진행률 업데이트는 이 카드 하나로 일원화
  • 진행률 섹션 — percentage + bar + 3-grid (현재/전체/읽은 날) · 보기 전용 (slider/저장 제거)
  • AI 토론 진입 — '방긋이랑 얘기해요' 카드로 대화 진입점 유지
  • 서브 액션 2개 — 문장 긋기 / 서평 쓰기 (동등한 secondary, 가로 2열)
  • Kebab 메뉴 — 완독 처리 / 공유 / 중단 / 삭제 (destructive는 빨간색 분리)
  • 100% 자동 프롬프트 — 완독 모달 → 서평 쓰기 유도 (Taasha 전환 훅)
  • Undo Toast 3초 — 진행률 저장 직후 실수 취소 가능 (Emily 엣지케이스)

엣지케이스 커버 (Emily)

  • total_pages가 null: Focus Card 대신 '오늘 읽었어요' 단순 버튼 + Kebab의 '완독 처리' 메뉴로 수동 처리
  • 100% 초과: 직접 입력 시 max(total_pages) clamp
  • 완독 모달 거절 후 재진입: localStorage('book_complete_dismissed_' + id)로 세션 내 1회만
  • +N 칩 연타 스팸: Dan 제안 — 1초 debounce
  • 접근성: 칩은 role="radiogroup", CTA는 aria-disabled 시 설명 제공, 시니어 대응은 '직접' 입력에서 큰 숫자 패드 + slider fallback

디자인 토큰 (Gail)

  • 배경 --bg:#F7F3ED cream · 카드 --sf:#FFFFFF · accent --ac:#5FA48E 민트
  • 본문 Pretendard · 숫자/메타 하이라이트 Gaegu (일기장 메타포, 핸드라이트 온기)
  • Focus Card만 box-shadow:0 6px 18px mint/10% · 나머지는 border로만 구분 (editorial 여백)
  • Destructive 컬러 --danger:#C55E4A — 민트와 상보색, Kebab에서만 등장
