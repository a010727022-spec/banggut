📚 책에 모임 있음 → V3 모임 대비형
  └ D-3 ~ D-Day 단계별 강도 업. 다른 HERO 덮어씌움.
📖 책에 모임 없음 → V1 체인 · 유저 상태에 따라 자동 분기
  └ V1-B 회상형 — 스크랩 3개+ 있으면 본인이 썼던 문장 회상 · 환각 0%
  └ V1-A 범용 질문형 — 스크랩 없고 읽는 중이면 책 무관 오픈 질문풀
  └ V1-C 넛지형 — 신규/거부감은 칩 하나만, 대화창에서 사용자가 먼저 말해요
이벤트 덮어씌움 — 특정 타이밍에만 한시적
V2 완독 골든타임 — reading → finished 전환 직후 24~48h (서평 전환율 핵심)
V4 슬럼프 복귀 — 이 책 last_read > 7일, "여기서 멈추셨어요" 회상 톤
V5 발견 재추천 — 완독 후 5일+ 공백, V2 식은 뒤 다음 책 제안
// 구현 의사 코드 — 한 함수로 해결 function resolveHeroVariant(user, book) { // 1. 이벤트 카드 (최우선 · 한시적) if (freshlyFinished(book, 48h)) return 'V2'; if (daysSinceRead(book) > 7) return 'V4'; if (noActiveBook(user, 5d)) return 'V5'; // 2. 모임 책은 V3 덮어씌움 if (book.group_books?.length) return 'V3'; // 3. 기본 V1 체인 (유저 상태 분기) if (user.scrapCount >= 3) return 'V1-B'; if (book.progress >= 0.15 && book.progress <= 0.85) return 'V1-A'; return 'V1-C'; }
※ 핵심 원칙: AI가 책 본문을 모른다는 전제. 그래서 구체적 책 내용 해석은 안 하고, 사용자가 쓴 문장을 회상하거나 책 무관 오픈 질문만 던져요. "AI가 틀린 소리 하네" 역효과 원천 차단.
