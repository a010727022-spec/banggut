① 목표 선택 (5가지)

☕ 15분 (가볍게) · 📖 25분 (집중 한 세션) · 🌿 45분 (깊게) · ✨ 60분 (완전 몰입) · ⏳ 자유 (목표 없음)
기본값: 25분. 사용자 설정 저장(다음에 같은 값으로 시작).

② 진행 중 링

목표 시간 대비 진행도 시각화. 남은 시간 표시. 자유 시간 선택 시 경과 시간만 카운트업.

③ 목표 도달 알림

목표 시간 도달 시 자동으로 축하 화면. "5분 더" 또는 "마치기" 선택. 진동/소리(설정 가능).

④ 완료 시트 확장

- 페이지 확정: 시작 쪽 + 읽은 쪽 자동 계산
- 기분 4개: 몰입/잔잔/복잡/졸림
- ✏️ 기억에 남는 문장: 선택 입력. 저장 시 자동으로 스크랩에 추가. 페이지 번호 함께
- 💭 느낌 한 줄: 선택 입력. 세션 노트로 저장
- AI 토론 자연스런 연결: 방금 쓴 구절을 바로 대화 재료로
