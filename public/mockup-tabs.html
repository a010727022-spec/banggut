❌ 현재 — 외곽선 pill

각 탭이 동일한 무게로 경쟁. 활성 탭만 녹색 bg. 특색 없음

A · 애니메이션 언더라인

Apple / Threads / Notion 스타일. 텍스트 중심. 깨끗하고 타임리스. 애니메이션 indicator가 슬라이드.

💚 B · Segmented Pill (추천)

iOS / Superhuman / Linear 스타일. 컨테이너 안에 들어있는 필. 활성 탭 흰 카드 + 부드러운 그림자. 가장 프리미엄 느낌. 폼 컨트롤이랑 같은 언어.

C · 개구체 + 아이콘

방긋 전용. 개구체 타이포 + 마이크로 이모지 + 민트 그라데이션 언더라인. 독창적, 따뜻함. 다만 정보 밀도 높음.

💚 제 추천: B
이유: (1) 스탯 카드와 카드 언어 통일 (감싸는 컨테이너) (2) 활성/비활성 대비 명확 (3) 카운트 배지도 같이 디자인 정돈 (4) 모바일 표준. 옵션 A도 좋지만 좀 차가움. C는 특색 있지만 호불호.

어느 거로 갈까요? A / B / C
