🌿 컨셉 · 세션이 주인공, 페이지는 따라붙어요

방긋에서 독서의 증거가 '몇 페이지 읽었나'에서 '얼마나 함께 있었나'로 이동해요. 뽀모도로 링을 책의 맥박으로 삼고, 진행률 · 포맷 토글 · 페이지 입력은 세션 플로우에 흡수돼요.

상태별 할 일

  • Idle: honey 그라데이션 링 + 집중 시작하기 · 아래 · 바로 페이지만 적을래요 안전망 링크 · 진행률은 얇은 strip(상단)
  • Running: mint 링이 진행 + 호흡 애니메이션 · 일시정지/중단 · 퀵액션/접기 희미하게 · 방해 최소화
  • Done: honey glow + 🌿 리캡 · 세션에서 읽은 페이지를 인라인으로 묻기 (124 → 160) · 건너뛰기 링크 · "오늘 2번째 · 누적 50분" 서사

이렇게 정리돼요

사라지는 것

  • 퀵액션 진행률 업데이트 버튼 ①
  • 큰 CTA 오늘 읽었어요 ③
  • showTodayModal 바텀시트
  • showProgress 상세 카드 ④

남는 것 · 이동

  • 뽀모도로 카드 (Hero로 승격)
  • 얇은 진행률 strip (포맷 토글 포함) ② 압축
  • 책 정보 수정 — 접기 섹션으로
  • 꾹 누르기 완독 — 유지

🎨 디자인 토큰 · 메모

  • Primary: --honey #D4A056 → --honey2 #B5803E 그라데이션 (뽀모도로 idle/done)
  • Secondary: --ac #5FA48E mint (running 중에만)
  • 카드 배경: #FCF5E6 → #FFF7E5 → #F7EFD8 세로 그라데이션 + 코너 radial glow
  • 타이포: 숫자 · 카피 세리프는 Fraunces (무료 · Pretendard 보완), 본문은 Pretendard
  • 링: 두께 8px(idle)→10px(running), stroke-linecap round, honey/mint gradient + drop-shadow
  • Motion: running 링에 breathe 4s 소폭 pulse · 1개 ring-pulse wave (반복) · prefers-reduced-motion 존중

🧪 구현 메모 (Dan)

  • FocusSessionCard 를 idle/running/done 3-state hero로 확장 (이미 state 분리됨 — 스타일만 승격)
  • 세션 Done 시 페이지 인라인 input 추가 → saveField({current_page})로 직접 저장. 그 자리가 유일한 페이지 업데이트 entry.
  • 진행률 카드는 strip 한 줄로 축소 (≈36px 높이). 포맷 토글 내장.
  • showProgress 카드 → <details> 접기로 이동 (전체 페이지·시작일·완독일만).
  • 퀵액션: 진행률 업데이트 버튼 삭제, 문장 긋기 + 서평 2열.
  • 큰 CTA 오늘 읽었어요 삭제. 꾹 누르기 완독은 하단에 유지.
  • 스트릭 판정: 오늘 FocusSession 1건 이상 완료 시 스트릭 칠.
