추가된 시각 시그니처

  1. 도그이어 fold — Focus Card 우측 상단 20도 접힘, 접힌 면에 오늘 날짜 embossed. 실제 책 모서리 느낌. Focus Card 전용 시각 앵커
  2. 북마크 리본 대롱 — 진행률 바 현재 위치에서 북마크가 매달림. Gaegu로 쪽수 표시. 막대 그래프에 물성을 준 단 하나의 디테일
  3. 책등(book-edge) streak — 도트 5개 대신 얇은 세로선 5개 + 하단 밑줄. 읽은 날이 쌓이면 책등이 두꺼워지는 느낌
  4. 포지션 뱃지 — "후반부 진입" / "마지막 챕터" 같은 감정 단어를 제목 옆에. 수학 아닌 서사. progress < 30=도입 / 30-60=중반 / 60-85=후반 진입 / 85-100=마지막 챕터
  5. 어제 문장 cameo — 어제 그은 스크랩을 Focus Card 아래에 마스킹테이프로 비스듬히 붙여놓음. 스크랩 없으면 이 블록 숨김
  6. 멤버 flag (Group only) — 진행률 바 위에 각 멤버 깃발. 아바타 컬러 매칭 · 내 북마크는 아래쪽(대롱) / 멤버는 위쪽(깃발)으로 구분

구현 메모

  • 모두 순수 CSS (clip-path, gradient, transform, drop-shadow)
  • 도그이어 접힘면은 background layering 2단 + drop-shadow로 입체감
  • 책등 streak은 today 마크만 약간 더 길고 glow
  • 북마크 리본의 tail은 clip-path:polygon(0 0,100% 0,50% 100%)로 V자 자르기
  • Cameo는 transform:rotate(-1.2deg)로 약간 비뚤게 + 마스킹테이프는 ::before로 얹음
  • 멤버 flag는 position absolute + 삼각형 clip-path
  • prefers-reduced-motion이면 pulse 애니메이션 해제

유지되는 원칙

  • Solo가 기본 · Group은 book.group_books 있을 때 모듈 교체
  • 표지 팔레트 ambient tint (책마다 무드 다름)
  • Pretendard 본문 + Gaegu 감정 포인트 (숫자·날짜·이름·포지션)
  • 진행률 업데이트 일원화 · Kebab에 중단/삭제 격리
