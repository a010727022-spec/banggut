💡 구현 계획
A) 취향 추천 섹션 (상단 새로 추가)
• 프로필 preferred_genres를 로드
• 알라딘 API에 장르별 추천 API 호출 (또는 전체 베스트셀러에서 필터)
• 장르 칩: 프로필 장르 Highlight + "+ 변경" 칩으로 장르 프로필 수정

B) 상태 선택 바텀시트 (새로)
• 책 선택 시 바로 등록 대신 바텀시트 오픈
• 3개 옵션: 읽는 중 (기본) / 위시리스트 / 완독한 책
• DB 저장 시:
  - 읽는 중 → reading_status=reading, started_at=now
  - 위시 → reading_status=want_to_read (시작일 없음)
  - 완독 → reading_status=finished, started_at=now, finished_at=now, progress=100%
