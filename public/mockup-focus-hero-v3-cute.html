🫘 완독콩 귀여움 재료

"세상의 모든 귀여운 UI" 를 완독콩 정체성에 녹였어요. 스티커 그림자 · 콩이 캐릭터 · 손글씨 포인트 · 종이 배경 · pastel pop · ±3deg 기울기.

🎨 팔레트

cream honey mint peach rose lavender sage 콩알

🫘 콩이 3포즈

  • Idle — 반짝눈 · 책 펼쳐 들고 대기 · 작게 wiggle 회전 애니메이션 · 머리 위 🌱
  • Running — 눈 감은 평온 ~~ · 책 읽는 중 · 주변에 z z 떠다님 · 링 breathing + ring-pulse wave
  • Done — 만세 🙌 · 큰 미소 ^ ^ · 주변 ✦ 컨페티 · 🫘 콩알 +1 스티커

✨ 귀여움 장치들

  • 스티커 그림자: 3px/4px offset, 검정 톤 (neo-brutal cute). 라벨은 ±3deg 기울여 '붙인 듯' 연출
  • 손글씨 포인트: Gaegu로 제목·라벨·숫자 서브 ("같이 읽을까요?", "10분 28초째 함께")
  • Fraunces 세리프: 시간 숫자(25:00)와 진행률(23%)에만 강조
  • 종이 배경: 18px radial-dot pattern + 두 개 pastel radial glow (허니 좌상 · 민트 우하)
  • 콩알 보상: 세션 완료 = 🫘 +1 스티커 팡파레. 프로필에 누적 콩알 배지로 연결 여지
  • 데코 이모지: 🌼 ✨ ⭐ 🌿 💤 💛 🎉 — 카드당 3~5개, 모서리 살짝 밖으로 삐져나와 스티커 느낌
  • 상태 배지: 좌상단 phone-state 라벨도 ±3deg 기울어진 스티커
  • 말풍선 형태: 시간 캡슐 25:00 이 링 위에 툭 걸친 라벨로 들어감
  • prefers-reduced-motion: wiggle · pulse · breathe 모두 static으로 돌아감

🧩 구현 매핑 (Dan)

  • components/book-detail/FocusSessionCard.tsx 의 3-state 렌더를 이 hero 구조로 확장
  • 콩이 3종 SVG는 components/book-detail/KongyBean.tsx (idle / running / done variant prop)
  • 스티커 라벨은 <Sticker variant="streak|tag|bean|today"> 재사용 컴포넌트
  • Done state 리캡 input → saveField({ current_page: N }) 로 저장. 여기가 유일한 페이지 업데이트 경로
  • 기존 showTodayModal 바텀시트 · showProgress 카드 · 퀵액션 진행률 업데이트 · 큰 CTA 오늘 읽었어요 → 모두 삭제
  • 진행률 카드(L1502-)는 한 줄 strip 으로 압축 · 포맷 토글 내장
  • 접기 accordion 에 전체 페이지 수정 · 시작/완독일 · (optionally) 포맷 전환 상세
  • Gaegu · Fraunces 는 app/layout.tsx 에서 next/font/google 로 로드 (이미 Gaegu 있으면 재사용)

🧪 세부 체크

  • 접근성: 스티커 라벨에 aria-hidden or role="img" aria-label 적절 부여
  • 다크모드/프라다 테마: honey / mint 그라디언트는 var(--ac), var(--honey) 로 참조, 하드코딩 #값 최소화
  • 모바일 터치 타겟: CTA 최소 44px 높이 유지
  • tilt/rotate는 -3deg ~ +3deg 내로만 — 과하면 엔터프라이즈 아님 · 방긋 아님
