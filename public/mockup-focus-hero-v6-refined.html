v6 refined — 무엇이 바뀌었나

v5가 스티커 4가지 컬러를 병렬로 쓰며 "귀여움"을 컬러로 증명했다면, v6는 브랜드 sage 한 톤 + 허니 한 번으로 팔레트를 묶고, 귀여움은 마스코트·도장·Gaegu 카피에만 위임했어요. 정보량·기능은 동일하게 유지됩니다.

팔레트 잠금

역할토큰용례
Canvas--bg #F5EEDEdot paper 배경, 카드 밖 전부
Ink--ink #2B2420본문 텍스트, 1.5px 테두리, 그림자 오프셋
Sage (brand)--sage #5FA48ECTA, 진행 막대, 도장 점, 수치 강조
Honey (축하)--honey #E8A93FPhone C 리워드 카드 딱 한 군데

v5에 있던 mint / peach / rose / lavender / kong-pink 파생 토큰은 모두 드롭. 민트 대신 sage를 쓰고, 허니는 Phone C 외엔 등장 금지.

디자이너가 조정한 포인트

회전각 규칙

모든 카드 ±3°
→ 카드 0° 고정. 리워드·캘린더 도장 같은 감정 모멘트에만 ±4° 허용.

그림자 1톤

honey / mint / peach 컬러 오프셋 3종
→ 2px 3px 0 rgba(43,36,32,.08) 단일 ink 톤.

스탯 카드 통합

3색 스티커 3개 나란히
→ 1 카드 · hairline dashed 구분. 숫자는 Fraunces 18px, 단위는 12px Pretendard.

타이포 위계

모든 수치는 Fraunces, 라벨은 Pretendard 600, 감정 카피만 Gaegu. 색 대신 서체로 계층을 분리.

Legend 제거

상단 3-마스코트 범례 카드
→ Phone A/B/C 태그와 마스코트 포즈가 이미 설명을 함. 중복 해소.

CTA 버튼

sage 솔리드 + sage-deep 테두리 · 그림자는 sage 62% 오프셋. "시작 버튼은 브랜드 컬러로" 원칙 명확히.
