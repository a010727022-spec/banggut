드림팀 회의 결정 요약

  • 등장 타이밍 — 첫 책 등록 완료 직후 자동. 이후엔 설정에서 변경 가능
  • 화면 구조 — 상단 3-탭 썸네일 + 하단 Live Preview(실제 책 반영) + 설명 카드 + CTA
  • 프리뷰 모션 — 3초 CSS 애니메이션 루프: 책꽂이는 새 책 슬라이드, 큐레이터는 카드 페이드, 스택은 책 파일 바운스
  • 헤드라인 — "책과 어떻게 살아갈까요?" (정체성 질문) 또는 변주 앵글
  • 서브헤더 — "나중에 설정에서 바꿀 수 있어요" (선택 스트레스 ↓)
  • 기본값 — 변주별로 다르게: A=책꽂이형 / B=큐레이터형 / C=스택형 (어떤 기본값이 가장 안전한지 관찰하기 위해)
  • CTA — "이 스타일로 시작하기" · 스킵 버튼 없음 (기본값으로 우회 가능)
  • 완독콩 — 헤더 좌측 상단 말풍선 옆에 작게. `prefers-reduced-motion` 준수
  • 접근성 — 모든 탭 버튼 키보드 접근 가능, ARIA selected 속성, 애니메이션 비활성 옵션 지원
