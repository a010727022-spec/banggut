# Design Brief: 방긋 전체 재설계

## Problem

독서하고 싶은데 혼자서는 잘 안 되고, 독서 모임에 끼고 싶은데 시간이 없다. 막상 책을 읽어도 며칠 지나면 내용이 희미해진다. 읽은 책에 대해 누군가와 이야기하고 싶은데 주변엔 같은 책 읽은 사람이 없다. 독후감/서평을 쓰고 싶지만 빈 화면 앞에 앉으면 뭘 써야 할지 막막하다.

**결국 "읽었다"는 사실만 남고 "읽은 경험"은 사라진다.**

## Solution

방긋은 **방긋이라는 캐릭터가 옆에서 같이 읽어주는 독서 동반자 앱**이다.

- **읽는 중엔** 방긋이가 말을 걸어준다 ("오늘도 한 장 같이!")
- **읽은 후엔** 방긋이와 AI로 5분간 가볍게 토론한다 — 오프라인 모임 없이도 내 생각을 말로 꺼내볼 수 있다
- **토론 내용이 자동으로 서평의 뼈대가 된다** — 빈 화면이 아니라 내가 방금 말한 내용을 다듬어서 발행하면 끝
- **목적성 있는 온라인 모임**에 참여해 다른 사람과 같은 책을 함께 읽는다

독서 경험이 캐릭터와의 대화 기록으로 오래 남는다.

## Experience Principles

1. **방긋이 우선, UI는 조용히** — 방긋이가 화면의 주인공. 카드·버튼·그리드는 캐릭터를 돋보이게 하는 배경일 뿐. 세련된 에디토리얼 무드는 철저히 배제.

2. **기능 단축, 경험 확장** — 앱은 4탭 네비(서재/모임/서평/MY)를 유지하지만 각 탭 안에서는 "다음 동작" 하나만 명확하게 제시. 기능을 다 보여주지 말고, 지금 할 일 하나를 보여준다.

3. **대화에서 기록으로, 끊김 없이** — AI 토론 종료 시점이 서평 작성 시작 시점이어야 한다. "토론 → 서평 발행"이 한 흐름 안에 있어야 "쉽게 쓴다"가 성립한다.

## Aesthetic Direction

- **Philosophy**: **Playful / Toy-like** (캐릭터 중심 앱 미학) — 에디토리얼·미니멀·브루털리즘 일체 배제
- **Tone**: 따뜻하고 다정하지만 **절제된 정돈감**. 유치하지 않고, 세련을 가장한 차가움도 없음
- **Reference points**:
  - **날씨돌이**: 캐릭터가 UI 장악. 의성어·이모지 자유롭게 활용. 귀여움이 기능의 일부
  - **북적북적**: 따뜻한 독서 기록 앱. 크림/베이지 톤. 글귀 중심
  - **고양이 책집사**: 캐릭터 + 독서 + 일본 스티커 감성
  - **모지토 / 투두메이트**: 깔끔한 캐릭터 기반 기록 앱의 정돈된 레이아웃
  - **혼플러스 / 오하루**: 감성적인 한국 라이프스타일 앱
- **Anti-references**:
  - Literal, Fable, Oku (미니멀 에디토리얼 — 너무 어른스럽고 차가움)
  - Readwise Reader (정보 밀도 높음 — 방긋은 감성 중심)
  - Goodreads (커뮤니티 리뷰 사이트 느낌 — 방긋은 개인 공간)
  - Notion 스타일 (기능적 — 방긋은 감정적)

## Existing Patterns

### 현재 코드베이스 상태 (유지 + 확장 대상)
- **폰트**: Pretendard Variable (UI), Gaegu (감성 카피), ~~Fraunces (폐기)~~
- **컬러 테마**: 5개 테마 시스템 (dark/cream/navy/sepia/blossom) + CSS 변수 (`--ac`, `--ac2`, `--bg`, `--sf` 등)
  - **cream이 기본이자 권장**. 다른 테마는 개인 취향 옵션으로만
- **스페이싱**: 일반적으로 margin `0 20px`, 카드 radius 14-18px
- **컴포넌트**: `FeaturedCard`, `BookTile`, `StatsWidget`, `AppHeader`, `BottomNav`, `EmptyState`
- **아이콘**: lucide-react (SVG), 방긋이 PNG (mascot-read/happy/sleep/welcome/worried)
- **상태 관리**: Zustand (auth, library, theme, discussion, scrap)
- **DB**: Supabase (books, reading_sessions, scraps, profiles, groups)

### 제거 대상
- Fraunces Light 숫자 (폐기 — 에디토리얼 무드 유발)
- StatsWidget (홈에서 제거됨 — 지저분함)
- "계절 독자 / 독서 체온" 개념 (프로필 페이지에 아직 남아 있음 — 제거 예정)
- 너무 두꺼운 하단 네비 (94px → 56-64px로 축소)
- 홈 레이아웃 3종 분기 (canvas/reading/community) — 단일 홈 + 방긋이 히어로로 통합 재고

## Key Interactions

### 1. 홈 진입
- 방긋이가 첫 화면의 히어로. 표정이 오늘 상태에 따라 다름 (읽었으면 happy, 이틀 이상 안 읽었으면 worried, 자정 이후 sleep)
- 말풍선 한 줄: "어제 157쪽에서 멈췄어요"
- 방긋이 탭하면 → 바로 이어읽기

### 2. 읽기 시작
- 이어읽기 버튼 탭 → 세션 시작 시트 (15/25/45/60/자유)
- 타이머 중 방긋이는 작은 플로팅 상태로 계속 보임 (같이 읽는 느낌)

### 3. 읽기 종료 → 토론 → 서평 (킥)
- 세션 종료 시트: 몇 쪽 읽었는지, 기분, 글귀 한 줄
- 끝나면 "방긋이와 이야기 나눌까요?" 제안
- 방긋이가 질문 던짐 ("오늘 가장 마음에 남은 장면은?")
- 3-5턴 대화 후 **"이 대화를 서평 초안으로 만들까요?"** → 1초만에 초안 생성
- 초안을 다듬어서 발행. **빈 화면 없음.**

### 4. 모임
- 같은 책을 읽는 목적 있는 모임 목록
- 가입 시 "읽기 페이스" 공유 (주 50쪽 등)
- 다른 멤버들의 스크랩/서평이 피드로 뜸

## Responsive Behavior

- 모바일 퍼스트 (360-414px 주 타겟)
- 태블릿/데스크톱은 `max-w-lg` 중앙 정렬로 동일 모바일 레이아웃 유지 (웹앱이지만 모바일 앱 시뮬레이션)
- 하단 네비는 `fixed bottom-0`, safe-area-inset 고려

## Accessibility Requirements

- 명암비 4.5:1 최소 (크림 배경 + 세이지 텍스트 특히 주의)
- 터치 타겟 44x44px 이상
- 방긋이 이미지에 alt text (장식인 경우 빈 alt)
- 키보드 내비 가능 (포커스 상태 명확)
- `prefers-reduced-motion` 지원 (방긋이 애니메이션 끌 수 있게)

## Out of Scope

이 브리프가 **다루지 않는 것**:

- 방긋이 꾸미기/옷장 기능 (프리미엄 BM — V2에서 고려)
- 소셜 그래프 (팔로우/팔로워, DM — 방긋은 개인 중심, 모임 단위 사교)
- 오프라인 모임 매칭 (타겟 유저가 온라인 선호 명시)
- 책 판매/쇼핑 연동 (알라딘/교보 검색만)
- 복잡한 통계 대시보드 (체온/계절 폐기)
- 낭독/오디오북 기능
- 다크모드 최적화 (cream 기본, dark는 옵션만 유지)
- 번역/다국어 (한국어 전용)
