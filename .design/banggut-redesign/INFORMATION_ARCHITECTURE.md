# Information Architecture: 방긋

## Site Map

4탭 하단 네비 유지. 홈은 서재 탭 안의 방긋이 히어로가 출발점.

- **서재** `/` ← 홈이자 첫 진입
  - 책 상세 `/book/[bookId]`
  - 책 찾기/추가 `/setup`
  - AI 독서 토론 `/discuss/[bookId]` (← 책 상세 또는 홈 CTA)
  - 서평 작성 `/review/[bookId]` (← 토론 종료 후 자동 연결)
  - 캘린더 `/calendar` (← 홈 위젯 "전체 보기" 딥링크, 탭 아님)
- **모임** `/groups`
  - 모임 상세 `/groups/[groupId]`
  - 모임 참여 `/groups/join?code=xxx`
- **서평** `/reviews` (← 기존 `/scrap`에서 개명·확장)
  - 보기 모드: 서평(기본) / 스크랩 / 토론 기록 (탭)
  - 서평 상세 `/review/[bookId]`
- **MY** `/profile`
  - 프로필 편집 (모달)
  - 설정 (테마, 알림, 목표, 도서관)
  - 구독/결제 (V2)
- 초대장 `/invite/[bookId]` (← 외부 진입 전용, 탭 밖)

### 라우트 재편 요약
| 기존 | 변경 후 | 비고 |
|---|---|---|
| `/` 안의 "오늘/읽는중/완독/위시/스크랩" 5탭 + 홈 레이아웃 3분기 | 홈은 **방긋이 히어로 + 이어읽기 + 서재 탭 4개(읽는중/완독/위시/스크랩)**, "오늘"은 탭이 아닌 히어로 자체 | 홈 레이아웃 선택 기능(profile.home_layout) 폐기 |
| `/calendar` (별도 하단 탭) | **하단 탭에서 제거**, 홈 내 캘린더 위젯에서 딥링크만 유지 | 네비 공간 회수 |
| `/scrap` (스크랩 리스트) | `/reviews`로 개명, 서평 우선 + 스크랩/토론 기록 서브탭 | 서평이 핵심 아티팩트 |
| `/discuss/[bookId]` 종료 후 | **자동으로 `/review/[bookId]?from=discussion` 이동** | 대화→기록 끊김 없음 |
| 홈 내 `?tab=today` 쿼리 | 제거 (기본이 히어로 상태) | |

## Navigation Model

### Primary navigation — 하단 4탭 (기존 구조 유지, 디자인만 재설계)
1. **서재** (`/`) — 홈 + 내 책들
2. **모임** (`/groups`) — 목적성 있는 독서 모임
3. **서평** (`/reviews`) — 내가 쓴 서평, 그은 문장, 토론 기록
4. **MY** (`/profile`) — 프로필, 설정, 구독

> 최대 4개로 고정. "캘린더"는 독립 탭이 될 만큼 자주 쓰지 않음 — 홈 위젯으로 충분.

### Secondary navigation — 탭 내부 서브탭
- **서재 홈**: 히어로(고정) → 수평 스크롤 서브탭 `읽는 중 / 완독 / 위시 / 스크랩`
- **서평 탭**: 세그먼트 컨트롤 `서평 / 스크랩 / 토론 기록`
- **모임 탭**: 세그먼트 컨트롤 `참여 중 / 둘러보기 / 초대 코드`
- **MY 탭**: 단일 스크롤 (섹션 구분 헤더)

### Utility navigation
- 헤더 우측 알림 벨 (모든 탭 공통)
- 헤더 좌측 아바타 → MY 딥링크
- 책 상세 내 공유/편집 버튼은 컨텍스트 메뉴로

### Mobile navigation
- 하단 고정 4탭, 높이 **60px** (현재 94px → 축소). safe-area-inset 포함
- 스크롤 시 살짝 반투명 + blur 유지
- 책상세/토론/서평/초대 페이지에선 네비 숨김 (몰입 유지)

## Content Hierarchy

### 서재 홈 (`/`)
1. **방긋이 히어로** — 첫 진입의 주인공. 표정/말풍선이 독서 상태 반영. 탭 시 바로 이어읽기.
   - *이유: "방긋이랑 같이 읽는 기분"이 핵심 가치. 캐릭터가 먼저 보여야 정체성 성립.*
2. **이어읽기 카드** — 가장 최근 읽던 책의 표지·진행률·CTA.
   - *이유: 사용자가 앱 여는 가장 흔한 이유 = "어제 어디까지 읽었지?"*
3. **오늘의 넛지** — 위시 시작 예정일, 모임 페이스 뒤처짐 등 가장 시급한 1-3개만.
   - *이유: 넛지가 많으면 소음. 방긋이 캐릭터 톤으로 1-3개만.*
4. **캘린더 위젯** — 스트릭 + 다가오는 일정 요약. "전체 보기 →" 로 `/calendar` 딥링크.
5. **서재 서브탭** — 읽는 중 리스트 (기본), 완독/위시/스크랩 수평 스크롤.
6. **AI 토론 CTA** — "방긋이랑 이야기해요" 진입점. (이어읽기 하단)

### 서평 탭 (`/reviews`)
1. **서평 세그먼트 (기본)** — 내가 발행한 서평 카드 그리드. 최근순.
2. **스크랩 세그먼트** — 책별 그룹된 하이라이트 문장.
3. **토론 기록 세그먼트** — 방긋이와의 과거 대화 아카이브.
4. **빈 상태** — "첫 서평을 써볼까요?" + 완독한 책 중 서평 없는 책 리스트.

### 모임 탭 (`/groups`)
1. **참여 중인 모임 카드** — 책 표지, 이번 주 목표 페이지, 내 진행률 vs 그룹 평균.
2. **둘러보기 (공개 모임)** — 주제별 모임 추천.
3. **초대 코드로 참여** — 6자리 코드 입력 CTA.

### 모임 상세 (`/groups/[groupId]`)
1. **책 + 목적** — "함께 읽는 이유" 한 줄 (주최자 작성)
2. **이번 주 페이스** — 목표 페이지 vs 내 진행
3. **멤버 스크랩 피드** — 다른 멤버들이 그은 문장 타임라인
4. **토론방 진입** — 공동 AI 토론 (V2)

### MY (`/profile`)
1. **프로필 카드** — 아바타, 닉네임, 스트릭
2. **이번 해 독서** — 간단한 수치 (완독 N권, 평균 별점, 인생책 N)
3. **독서 목표** — 연간/일간 목표 수치
4. **테마 · 알림 · 도서관** — 설정 3종
5. **구독** (V2) — 방긋이 프리미엄
6. **로그아웃**

> 폐기: 체온 상세, 독서 계절 그리드, 알림 루틴 복잡 설정, 홈 레이아웃 선택

## User Flows

### Flow 1: 이어읽기 → 토론 → 서평 (핵심 킥)
1. 사용자가 앱 열고 서재 홈 도달
2. 방긋이 히어로가 "어제 157쪽에서 멈췄어요" 말풍선 노출
3. 방긋이 탭 또는 이어읽기 카드 탭
   - 처음 이어읽기 → 세션 시트 (15/25/45/60/자유 선택)
   - 타이머 돌아감 (방긋이 작은 플로팅 상태)
4. 세션 종료 → 완료 시트 (쪽수/기분/글귀/메모)
5. 완료 시트 하단: **"방긋이와 이야기 나눌까요?"** 제안
   - 예 → `/discuss/[bookId]` 로 이동
   - 아니오 → 홈 복귀
6. 방긋이 질문 3-5턴 진행
7. 토론 종료 시 **"이 대화를 서평으로 만들까요?"** CTA
   - 예 → `/review/[bookId]?from=discussion&draft=auto` (AI가 대화에서 서평 뼈대 자동 생성)
   - 아니오 → 토론 기록으로 저장 후 홈 복귀
8. 서평 에디터에서 초안 다듬기 → 발행
9. 서평 탭에 발행됨, 홈으로 복귀

### Flow 2: 신규 유저 — 첫 책 등록
1. `/onboarding` 완료 (닉네임, 아바타)
2. 서재 홈 도달 — 방긋이 "첫 책을 골라볼까요?" 말풍선 + 빈 상태 CTA
3. `/setup` 검색 → 책 선택 → 상태(읽는 중/위시/완독)
4. 서재 홈 복귀 — 방긋이 "같이 읽어요!" 표정 변화 + 이어읽기 카드 등장

### Flow 3: 모임 참여 → 함께 읽기
1. 모임 탭 → 둘러보기 or 초대코드 입력
2. 모임 상세 → "이 모임 참여하기"
3. 모임 상세 홈으로 이동 — 책 자동으로 내 서재 "읽는 중"에 추가됨
4. 서재 홈에 **모임 페이스 넛지** 등장 ("이번 주 80쪽까지 함께")
5. 내가 스크랩 남기면 모임 피드에 자동 공유

### Flow 4: 위시 → 시작
1. 서재 홈 → 위시 서브탭
2. 책 카드 탭 → 책 상세
3. "읽기 시작" → 상태 `reading`으로 전환 + 이어읽기 히어로에 바로 올라옴

### Flow 5: 스크랩 (책 읽다가 글귀 남기기)
1. 책 상세 → "글귀 스크랩" 버튼
2. 문장 입력 or OCR (사진 → 텍스트)
3. 저장 → 서평 탭 > 스크랩 세그먼트에 쌓임
4. 나중에 서평 작성 시 해당 책의 스크랩이 재료로 자동 노출

## Naming Conventions

일관된 용어가 핵심. **"하나의 개념 = 하나의 단어"** 고정.

| Concept | Label in UI | Notes |
|---------|-------------|-------|
| 사용자 본인 | **님**, **독서가** | "유저", "사용자" 사용 금지 |
| 반려 캐릭터 | **방긋이** | "마스코트", "캐릭터" 표기 금지 |
| AI 대화 | **이야기 나누기** / 내부 데이터는 *discussion* | "토론"은 내부용, UI는 "이야기" |
| 발행된 감상 | **서평** | "리뷰" 사용 금지 |
| 책 속 문장 저장 | **스크랩** | "하이라이트", "노트" 사용 금지 |
| 그은 문장 | **글귀** | 스크랩의 내용 단위 |
| 매일 연속 독서 | **이어가기** + 숫자 "N일째" | "스트릭" 미노출, 내부용 |
| 읽기 시간 측정 | **독서 세션** | "타이머" 대신 |
| 읽고 싶은 책 | **위시** | "위시리스트" 줄임 |
| 다 읽은 책 | **완독** | "읽음" 대신 |
| 독서 모임 | **모임** | "그룹" 사용 금지 |
| 모임 목적 문구 | **함께 읽는 이유** | 주최자 작성 |
| 일일 페이지 목표 | **하루 한 장** / 숫자 | "일일 목표" 대신 |
| 연간 권수 목표 | **올해 N권** | "연간 목표" 대신 (숫자 강조) |

## Content Growth Plan

성장하는 콘텐츠와 대응 패턴:

| 섹션 | 성장 방식 | 대응 패턴 |
|---|---|---|
| 서재 **완독** | 평생 누적 | 인스타 그리드 + 정렬(최근/별점/제목) + 스크롤 무한 |
| 서재 **위시** | 수십 권 누적 | 정렬(예정일순) + 태그 필터 |
| 서재 **스크랩** | 책당 수십 개 | 책별 그룹 접기 + 검색 |
| **서평** | 연 10-50개 | 최신순 카드 + 연도별 아카이브 |
| **토론 기록** | 책당 1-5개 | 책별 접기 + 일자 정렬 |
| **모임** | 사용자당 1-3개 동시 참여 | 리스트면 충분, 필터 불필요 |
| **모임 피드** | 매일 누적 | 최신순 + 오래된 건 7일 후 자동 접기 |

빈번하게 커지는 완독/스크랩은 **검색 + 필터**가 V1.5에 추가.

## URL Strategy

### 패턴
- 기본: `/section` 또는 `/section/[slug]`
- 예약 쿼리:
  - `?from=discussion` — 서평이 토론에서 이어짐을 표시
  - `?draft=auto` — 서평 초안을 AI가 자동 생성
  - `?tab=<name>` — 서재/서평/모임 내 세그먼트
  - `?sort=<name>` — 완독/위시 정렬

### 딥링크 예시
- `/discuss/abc123` — 책 abc123에 대한 토론
- `/review/abc123?from=discussion&draft=auto` — 토론 후 자동 서평 에디터
- `/reviews?tab=scraps` — 서평 탭의 스크랩 세그먼트
- `/calendar` — 캘린더 전체 (홈 위젯에서만 진입)
- `/groups/[groupId]?code=XYZ` — 초대 코드와 함께 모임 진입

### 규칙
- 소문자-하이픈-슬러그 (한글 slug 금지)
- 동적 세그먼트는 `[bookId]`, `[groupId]` 등 명시적 명명
- 공유 가능한 URL은 쿼리 파라미터 없이도 동작해야 함
- 인증 필요 라우트는 `(main)` 그룹, 비인증은 `(auth)` 그룹 (기존 구조 유지)
